# CGit

![cgit logo](image-1.png)

Edit files, make commits and revert changes. Made in C.

## This ~25h personal project helped me learn:
- C
- MakeFile
- CMake
- How to make my own linked list implementation
- Macros
- malloc, dealloc, realloc
- Editing files in C
- Address Sanitizer
- gdb
- installing a linux subsystem on my windows machine
I also read a book on C before starting this project to learn the theory

## Quick Start

### Prerequisites
- Operating System: Linux
- Visual Studio Code installed with all dependancies for running C programs
- Git installed  

#### 1. Clone the repository
Run the following commands in a terminal session:
```bash
git clone https://github.com/Nafimul/cgit/tree/main
```

#### 2. Run the project
Open the cgit folder in visual studio code and click run. Follow on-screen instructions to run with CMake
